\# Azure BlueAcademy



A web-based study app built with JavaScript and wrapped into a mobile app using Capacitor.



\## Features

\- Azure/cloud study content

\- Offline support (service worker)

\- Mobile-ready app structure



\## Tech Stack

\- JavaScript (Vanilla)

\- Capacitor (iOS/Android wrapper)

\- Node.js

🚧 In development — converting into a full mobile app
